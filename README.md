# Museum Posters and Models — GitHub Pages App

Mobile-friendly static web application created from the supplied **Museum Posters and Models.docx**.

## GitHub Pages
Repository: `PHD-QR/museum-posters`
Expected URL: `https://PHD-QR.github.io/museum-posters/`

Upload the contents of this folder to the repository root. In **Settings → Pages**, choose **Deploy from a branch → main → / (root)**.

## QR code
The included QR code points to the website URL, not directly to the document. Therefore the same printed QR remains valid when the page images/content are updated, as long as the website URL stays unchanged.

## Updating the catalogue
Replace the page images in `assets/` and, if names/descriptions/page locations change, update `data/items.js`. Keep `config.js` and the public URL unchanged.
